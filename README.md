# Pemrograman Jaringan - Kumpulan Tugas

Repository ini berisi kumpulan tugas mata kuliah Pemrograman Jaringan.

Link repository Github: https://github.com/azra-ahmad/pjar-matkul/

## Daftar Tugas

| Lokasi | Tugas | Deskripsi |
| --- | --- | --- |
| `udp_client.py`, `udp_server.py` (root) | Tugas awal | Aplikasi UDP sederhana |
| `M8/` | Tugas M8 | Aplikasi chat UDP broadcast + TCP multi-client |
| `pre-uts/` | Tugas Akhir Pre-UTS | Aplikasi FTP file transfer (TCP) |

Masing-masing folder memiliki README tersendiri yang berisi penjelasan lengkap, cara menjalankan, dan screenshot hasil running.

## Informasi Umum

- Mata kuliah: Pemrograman Jaringan
- Bahasa: Python
- Platform pengujian: Server di VM Ubuntu (via SSH), client di Windows lokal
